# 문자열 덧셈 계산기
입력한 문자열에서 숫자를 추출하여 더한 값을 출력한다.

## 구현할 기능
### 입력
- [x] 구분자와 양수로 구성된 문자열 입력 받기
    - `덧셈할 문자열을 입력해 주세요.` 출력
    - `@woowacourse/mission-utils`의 `Console.readLineAsync()`를 사용하여 입력

- [x] 입력 유효성 검사
    - 양수가 아닌 값이 입력된 경우
    - default 구분자 사용 시 쉼표, 콜론 외에 다른 문자열이 포함된 경우
    - custom 구분자에 숫자가 포함된 경우
    - custom 구분자 사용 시 지정된 구분자 외에 다른 문자열이 포함된 경우

- [x] 사용자가 잘못된 값을 입력할 경우 에러 처리
    - `[ERROR]`로 시작하는 메시지와 함께 Error 발생
    - 애플리케이션 종료

### 문자열 파싱
- [ ] 구분자 설정
    - default: 쉼표(`,`) 또는 콜론(`:`)
    - custom: 문자열 앞부분의 `//`와 `\n` 사이에 위치하는 문자로 설정
- [ ] 구분자를 이용한 숫자 추출

### 계산 및 출력
- [ ] 추출한 숫자의 총합 계산
- [ ] 덧셈 결과 출력
    - `결과 : ${result}` 형식으로 출력
    - Console.print() 사용
